## 🎯 1. Problem & User

### a) เราจะแก้ปัญหาอะไร?
```
โปรเจกต์นี้ช่วยแก้ปัญหา การตรวจสอบการสวมหน้ากากอนามัยแบบอัตโนมัติ ครับ
โดยระบบสามารถวิเคราะห์ภาพถ่ายเพื่อแยกแยะได้ว่าบุคคลนั้นสวมหน้ากากอนามัยได้ "ถูก" หรือ "ผิด" วิธี (รวมถึงมีหมวดหมู่การประเมินว่าใส่แมสหรือไม่ใส่แมสด้วย) ซึ่งช่วยลดภาระของเจ้าหน้าที่ในการเฝ้าระวังความปลอดภัย และสามารถนำไปติดตั้งบนอุปกรณ์ฮาร์ดแวร์ขนาดเล็กเพื่อตรวจสอบได้แบบเรียลไทม์ครับ
```

### b) ใครคือ user หลัก?
```
เจ้าหน้าที่รักษาความปลอดภัยตามอาคารสำนักงานหรือโรงพยาบาล
ฝ่ายบุคคล (HR) หรือเจ้าหน้าที่ความปลอดภัย (จป.) ในโรงงานอุตสาหกรรม
ผู้ดูแลระบบจัดการคนเข้า-ออก (Access Control) ของพื้นที่ควบคุมเชื้อโรค
```

### c) ทำไม Edge AI ถึงเหมาะกับปัญหานี้? (ทำไมไม่ใช่ Cloud)
```
Privacy: ไม่ต้องอัปโหลดภาพใบหน้าของพนักงานหรือผู้มาติดต่อขึ้น Cloud ทำให้รักษาความเป็นส่วนตัวของข้อมูลได้ 100%
Latency: ต้องการการตอบสนองที่รวดเร็วเพื่อให้คัดกรองคนเดินผ่านประตูได้ทันทีโดยไม่เกิดคอขวด
Offline Reliability: สามารถทำงานได้แม้ในจุดที่อินเทอร์เน็ตไม่เสถียร หรือใช้งานร่วมกับประตูเข้า-ออกได้โดยตรง
```

## 💎 2. Value Proposition

### Unique Value (USP)
ในประโยคเดียว:

```
"MaskGuard Edge" ช่วย เจ้าหน้าที่รักษาความปลอดภัย ตรวจจับผู้ที่ไม่สวมหน้ากากอนามัยก่อนเข้าพื้นที่
ต่างจาก ระบบ AI กล้องวงจรปิดแบบ Cloud ทั่วไป เพราะ ประมวลผลได้รวดเร็วทันทีบนอุปกรณ์ ไม่ละเมิดความเป็นส่วนตัวทางข้อมูลใบหน้า และติดตั้งง่ายโดยไม่ต้องพึ่งพาอินเทอร์เน็ต
```

1. **ถ้าต้องอธิบายงาน 2 นาที ทีมควรแบ่งช่วงพูดกันล่วงหน้า**
2. **ถ้าต้องโชว์สด ควรมีแผนสำรองเมื่อ internet หรือ hardware มีปัญหา**
3. **Document ทุก iteration** ใน GitHub — commit ทุก hour
4. **Token = constraint ที่สอนการตัดสินใจ** — เลือกสิ่งจำเป็น
5. **ไอเดียดี + execute ไม่จบ < ไอเดียเรียบง่าย + execute เสร็จ**
