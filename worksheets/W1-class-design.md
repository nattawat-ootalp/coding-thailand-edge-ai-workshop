## 1. โจทย์ของทีม

**Problem statement** (1-2 ประโยค บอกว่าจะแก้ปัญหาอะไรในชีวิตจริง):

```
เราจะสร้างระบบตรวจสอบการสวมหน้ากากอนามัย (Mask Detection) ในอาคาร 
โดยใช้บอร์ด Arduino UNO Q (Qualcomm QRB2210) เพื่อคัดกรองและแจ้งเตือนผู้ที่ไม่ได้สวมหน้ากากหรือสวมใส่ไม่ถูกต้อง
```

---

## 2. Class Definition

ระบุ class ที่จะใช้ + เกณฑ์ที่ทำให้แต่ละ class แตกต่าง:

| # | ชื่อ Class | คำอธิบาย (3-4 ประโยค) | สิ่งที่ทำให้ต่างจาก class อื่น |
|---|---|---|---|
| 1 | ใส่แมส | ผู้ใช้งานสวมใส่หน้ากากอนามัยครอบคลุมทั้งจมูกและปากอย่างมิดชิด เป็นพฤติกรรมที่ถูกต้องตามมาตรการสุขอนามัย | ห็นตัวหน้ากากบดบังพื้นที่ใบหน้าส่วนล่างและสันจมูกอย่างชัดเจน |
| 2 | ไม่ใส่แมส | ผู้ใช้งานไม่ได้นำหน้ากากอนามัยมาสวมไว้บนใบหน้าเลย เผยให้เห็นโครงหน้าทั้งหมดชัดเจน | เห็นอวัยวะบนใบหน้าครบถ้วน ทั้งจมูก ปาก และคาง โดยไม่มีวัตถุแปลกปลอมบดบัง |

---

## 3. Edge Cases — สิ่งที่อาจสับสน

ระบุสถานการณ์ที่อาจทำให้โมเดลสับสน:

```
1. คลาส "ผิด" (ใส่แมสไม่ถูกต้อง) ถูกโมเดลสับสนและทำนายว่าเป็น "ใส่แมส" 100% (F1 Score ของคลาสผิดยังเป็น 0.00)

2. การใส่หน้ากากอนามัยสีเนื้อ หรือสีขาวที่กลืนไปกับสภาพแสงและสีผิวของผู้ใช้งาน

3. การใช้มือบดบังใบหน้า หรือการไว้หนวดเคราหนาๆ อาจทำให้โมเดลสับสนในคลาส "ไม่ใส่แมส" และ "ใส่แมส" (มี Error ระหว่างสองคลาสนี้ประมาณ 1.1% - 5.3%)
```

**วางแผนแก้:**
```
1. เพิ่มปริมาณ Data Collection ของคลาส "ผิด" ให้มากขึ้นและหลากหลายขึ้น (ถ่ายภาพคนดึงแมสไว้ใต้คาง หรือเปิดจมูกในหลายๆ มุม)

2. เปิดใช้งาน Data Augmentation ในหน้า Neural Network settings เพื่อช่วยให้โมเดลเรียนรู้การหมุน ภาพสะท้อน และความสว่างที่แตกต่างกัน

3. เพิ่มความหลากหลายของประเภทหน้ากาก (หน้ากากผ้า, หน้ากากอนามัยทางการแพทย์, สีต่างๆ) ในการเทรน V2
```

## 5. Diversity Plan — กันอคติ (Bias)

ตอบ 3 คำถาม:

### a) มีหลาย "environment" ไหม?
```
เก็บภาพทั้งในห้องเรียนที่มีแสงจากหลอดไฟฟลูออเรสเซนต์ และบริเวณทางเดินที่มีแสงธรรมชาติส่องเข้ามา เพื่อป้องกันโมเดลเอียงเอียงตามสภาพแสง + งdata samples free
```

### b) มีหลาย "subject" ไหม? (กรณี Vision/Audio/Motion)
```
เก็บข้อมูลจากใบหน้าของสมาชิกทุกคนในทีม (จีรวัฒณ์, ณัฐวรรธน์, กันตธี) รวมถึงเพื่อนๆ ในเวิร์กชอปเพิ่มเติมเพื่อให้โมเดลรู้จักโครงหน้าที่หลากหลาย รวมถึงdata samples free
```

### c) มีหลาย "variation" ไหม?
```
ถ่ายภาพในระยะห่างที่แตกต่างกัน (ระยะใกล้ 0.5 เมตร สำหรับสแกนรายคน และระยะ 1.5 เมตร สำหรับตรวจจับระยะเดินผ่าน) รวมถึงการหันหน้าตรงและเอียงซ้าย-ขวา 15-30 องศา
```

## 6. Output Plan

ทีมจะใช้ Modulino อะไรเป็น output? บอกผลลัพธ์ยังไง?

```
[ ] Modulino Buzzer — เสียง alertเมื่อพบคนใส่หน้ากากผิดและไม่ใส่หน้ากาก

```

**ตัวอย่าง:**
- "ผิด" → Buzzer beep 2 ครั้ง
- "ไม่ใส่แมส" → Buzzer beep 4 ครั้ง

## 7. Success Criteria

ทีมจะถือว่าโมเดลใช้งานได้เมื่อ:

```
[X] Accuracy V1 ≥ 96.7% (ปัจจุบันทำได้ตามเป้าหมายบน Validation set แล้ว)
[X] V2 ดีกว่า V1 อย่างน้อย 1.5% (เน้นแก้คลาส "ผิด" ให้ F1-Score มากกว่า 0.80)
[X] False negative ของ class สำคัญ (หลุดคนไม่ใส่แมสแต่บอกว่าใส่) ≤ 2%
[X] Inference ภายใน 200 ms (ทดสอบการประมวลผลบนฮาร์ดแวร์จริง Akida)
```
